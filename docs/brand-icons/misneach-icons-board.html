How to generate PNG files from the SVG
Canonical SVG source: docs/brand-icons/misneach-mark.svg
To generate PNGs at each size:

Node (sharp): sharp('misneach-mark.svg').resize(512).png().toFile('icon-512.png')
Inkscape: inkscape misneach-mark.svg --export-png=icon-512.png --export-width=512
ImageMagick: convert -background none misneach-mark.svg -resize 512x512 icon-512.png

For favicon.ico, generate 16/32/48 PNGs then combine with:
convert icon-16.png icon-32.png icon-48.png favicon.ico
