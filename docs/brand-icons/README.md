# Misneach Brand Icons

Source assets for favicon/app-icon generation live here.

## Files

- `misneach-mark.svg`:
  - Canonical vector mark (speech bubble + fada stroke).
  - Use this as the source for all exported sizes.
- `misneach-icons-board.html`:
  - Visual reference board and export guidance.
  - Includes sizing notes for favicon, app icons, and social image.

## Current usage

- Web favicon is wired to:
  - `apps/app-web/static/favicon.svg`

## Suggested future exports

- Favicon:
  - `16x16`, `32x32`, `48x48`, plus multi-size `favicon.ico`
- Apple touch icon:
  - `180x180`
- Android/PWA:
  - `192x192`, `512x512` (maskable variant too)
- Store/listing:
  - `512x512` app icon source
  - `1200x630` social/OG image
